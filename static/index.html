갱신 상태

엑셀 업로드참고 워크북과 같은 양식(raw / 정보입력 시트)

  • 업로드된 파일은 data/inbox/에 저장되고, 이후 스케줄 갱신 시 변경분이 자동 반영됩니다.
  • DART 갱신은 .env의 DART_API_KEY가 설정된 경우 상장사 손익·재무상태·현금흐름 총계를 가져옵니다. 판관비 세부 항목은 엑셀 입력값이 유지됩니다.
  • 스케줄은 REFRESH_SCHEDULE(cron 5필드)로 설정합니다. CLI: python -m app.refresh

상장 / 비상장 구분과 DART 데이터 범위

구분연간분기이 대시보드에서
상장 상장사사업보고서 · API 제공분기·반기보고서 · API 제공DART 갱신으로 손익·재무상태·현금흐름 총계 자동 갱신
사업보고서 제출 비상장사 (대형)사업보고서 · API 제공분기·반기보고서 · API 제공위와 동일 (DART 기업코드가 매핑되면 자동)
비상장 일반 비상장사감사보고서 · 공시 원문만없음API 미제공 → 엑셀(raw 시트) 입력값 유지. 갱신 이력에 "건너뜀"으로 표시
  • 판관비 세부 항목(인건비·광고선전비 등)은 주석 데이터라 상장사도 API로 제공되지 않습니다. 모든 기업의 판관비 세부는 엑셀 입력값을 씁니다.
  • 상장 여부는 초기 데이터에 수동 입력된 값이며, DART 갱신 시 DART 종목코드 유무로 자동 확정됩니다. 엑셀 정보입력 시트에 상장 컬럼(O/X)을 두면 그 값을 우선합니다.
  • 스크리너의 "상장 전체" 필터와 기업명 옆 배지로 구분할 수 있습니다.
